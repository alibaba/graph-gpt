## 主要发现

### Pre-training Forward 输入

**必需的张量：**
```python
input_ids: [batch_size, seq_len, stacked_feat]  # token IDs
attention_mask: [batch_size, seq_len]            # 注意力掩码
labels: [batch_size, seq_len, 1]                 # 预测目标（-100 表示忽略）
```

**可选的张量：**
```python
inputs_raw_embeds: [batch_size, seq_len, embed_dim]  # 原始节点/边嵌入
position_ids: [batch_size, seq_len]                   # 位置编码
split_lens: List[int]          # flex attention 用的图边界
attn_modes: List[str]          # flex attention 用的注意力模式
```

### Fine-tuning Forward 输入

**必需的张量：**
```python
input_ids: [batch_size, seq_len, stacked_feat]   # token IDs
attention_mask: [batch_size, seq_len]             # 注意力掩码
task_labels: [batch_size, num_labels]             # 任务标签
```

**可选的张量：**
```python
cls_idx: [batch_size]              # 分类池化索引
sample_wgt: [batch_size]           # 样本权重
pretrain_labels: [batch, seq, 1]   # 辅助预训练标签
inputs_raw_embeds: [batch, seq, dim]  # 原始嵌入
split_lens: List[int]              # 图边界
attn_modes: List[str]              # 注意力模式
```

## 关键区别

### Pre-training vs Fine-tuning

| 特性 | Pre-training | Fine-tuning |
|------|--------------|-------------|
| **目标** | 预测 token | 预测图属性 |
| **主要标签** | `labels` (token-level) | `task_labels` (graph-level) |
| **损失** | 生成式/判别式 token 预测 | 分类/回归 |
| **辅助损失** | 可能有 SMTP | 可能有预训练 denoising |

### 配置影响

**Token Packing (`pack_tokens > 0`):**
- 多个图打包进一个序列
- `input_ids` 形状变为 `[1, packed_seq, feat]`
- 添加 `split_lens` 指示图边界

**Flex Attention:**
- 需要 `split_lens` 和 `attn_modes`
- 动态创建块对角注意力掩码
- 每个图独立注意力（无跨图注意）

**Node/Edge Embeddings (`embed_dim > 0`):**
- 添加 `inputs_raw_embeds` 输入
- 与 token embeddings 相加

## 数据流转

```
原始图 (PyG Data)
  ↓
Tokenization (Eulerian 路径)
  ↓
属性堆叠 (stacked_feat)
  ↓
Collation (批处理)
  ↓
Model Forward Pass
  ↓
Loss Calculation
```

## 调试方法

修改 `src/utils/training_utils.py`:

```python
    print("\n=== BATCH INSPECTION ===")

                  f"min={value.min():.4f}, max={value.max():.4f}")
    print("========================\n")
    
    # 继续 forward pass
    output = model(**data)
    ...
```

### 方法 2: 使用 Hook

```python
class ForwardInspector:
    def __init__(self):
        self.captured = []
    
    def hook(self, module, args, kwargs):
        self.captured.append({'args': args, 'kwargs': kwargs})
        for k, v in kwargs.items():
            if isinstance(v, torch.Tensor):
                print(f"{k}: {v.shape}")

# 使用
inspector = ForwardInspector()
model.register_forward_hook(inspector.hook)
```

在 `src/data/collator.py` 中添加调试输出:

## 常见问题排查

### 1. 设备不匹配错误
**错误:** "Expected device cuda but got cpu"

**解决:**
```python
batch = {k: v.to(device) for k, v in batch.items()}
```

### 2. 形状不匹配
**检查:**
- `stacked_feat` 与配置一致
- `batch_size` 正确
- `seq_len <= max_position_embeddings`

### 3. CUDA 内存不足
**解决:** 减小 `batch_size` 或 `max_position_embeddings`

### 4. 标签超出范围
**检查:** 确保 `labels < vocab_size` (除了 -100)
